## Theme and Storyline

**Theme:**

Haunted Mansion Escape – The player is trapped inside a haunted mansion and must explore the rooms to find the items needed to escape.

**Storyline:**

The player is trapped inside a haunted mansion and must collect six items before escaping. The player will explore different rooms to find a book, candle, key, map, flashlight, and amulet. The player must avoid the basement until all six items are collected because a ghost is waiting there. If the player enters the basement too early, the game is lost.

## Rooms

Project One requires a minimum of eight rooms.

1. Entrance Hall - Start room
2. Library
3. Kitchen
4. Bedroom
5. Study
6. Storage Room
7. Attic
8. Basement - Villain room

Add more rooms if your design needs them.

## Items

With the minimum eight-room design, Project One requires at least six items.
Every room except the start room and villain room must contain one item.

1. Book - Library
2. Candle - Kitchen
3. Key - Bedroom
4. Map - Study
5. Flashlight - Storage Room
6. Amulet - Attic

If you add rooms beyond the minimum, add an item for every additional room
except the start room and villain room.
